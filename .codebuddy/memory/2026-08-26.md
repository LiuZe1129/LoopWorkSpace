### Conformance 三态语义
- PASS：节点完成 + artifact 存在 + acceptance 映射完整
- UNVERIFIED：待证据（实现未完成 / artifact 不存在）→ SCR spec_gap
- FAIL：验收本身缺失（spec 缺陷：orphan requirement / automated 空检查）→ SCR acceptance_bug

### 全局安全底线（不分版本）
- Requirement 无任何 Acceptance 映射 → 不 PASS（1.1=FAIL, 1.0=UNVERIFIED）
- automated Acceptance check/expect 空 → FAIL
- 有文件存在不等于 PASS——必须验收映射完整 + 证据存在
