## 真机测试失败根因修复（同一会话）

用户真机测试 `172.12.2.108` 发现设备树只显示 1 个通道、预览黑屏、未达预期。核查发现根因：3 个测试全是离线/边界路径（PASS ≠ 真机正向功能），代码有 5 个实现缺陷。

### 5 个缺陷与对应修复

1. **P0 — queryChannelCount 硬编码 1** → `NetSdkWrapper.h/cpp` 新增 `DeviceInfo` 结构缓存 `NET_DEVICEINFO_Ex`；`loginWithHighLevelSecurity` 填充 `nChanNum`；`queryChannelCount` 直接读缓存。
2. **P0 — toRealPlayType 误用 DH_RType_Multiplay_N** → 改为统一返回 `0`（DH_RType_Realplay）；4/9 分屏由 PreviewGridWidget 创建多个独立 PreviewWidget 实现（方案 A）。
3. **P0 — PreviewWidget::paintEvent fillRect 覆盖 SDK 渲染** → 加 `WA_PaintOnScreen` + `WA_OpaquePaintEvent`；`paintEvent` 改为空实现。
4. **P1 — 错误码取法 out.nError 不可靠** → `loginWithHighLevelSecurity` 失败改用 `CLIENT_GetLastError() & 0x7fffffff`（与 init/logout 一致）。
5. **P1 — 设备断线/通道离线 UI 未响应** → `DeviceTreeView` 新增 `setDeviceOnline`/`setChannelOnline` + `StatusBadgeDelegate` 绘制在线/离线圆点（#27D05A/#E9463A）；`MainWindow` 连接 `deviceDisconnected`/`deviceReconnected`/`channelPreviewFailed` 信号；`PreviewWidget` 失败 emit `channelPreviewFailed` 经 PreviewGridWidget 转发。

### LoginDialog loading 改为 QTimer 文本 dots（非闪烁，符合 DESIGN.md §9.4）

### main.cpp 简化重复登录
LoginDialog 暴露 `loginId()` getter；main.cpp 直接复用，不再二次 `loginWithHighLevelSecurity`。
